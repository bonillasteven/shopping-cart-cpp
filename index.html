Shopping Cart System (C++)

Object-Oriented Programming | Data Structures | Real-World Simulation

📌 Project Overview

Developed a console-based shopping cart application in C++ that simulates real-world e-commerce functionality. Designed using object-oriented programming principles with classes for managing items and cart operations.

⚙️ Features

  • Add and remove items
  • Update item quantities
  • Automatic total cost calculation
  • Operator overloading for input/output

🧠 Skills Used

  • C++
  • Object-Oriented Programming (OOP)
  • Data Structures
  • Debugging & Problem Solving
